## R4. Ranked gaps and recommendation

1. **Fixture path is weaker than dispatch for slot validation.** The kit turns recorded replies into ops itself (`testkit.py:207–241`); the dispatcher validates slots before planning (`dispatch.py:874–926`). Treat C/P as complementary to A and focused real-dispatch tests, not as substitutes (`test_skills_acceptance_offline.py:103–118,505–544`).
2. **The primary acceptance inventory is not an intake-workflow inventory.** `item_intake` and `intake_simple` are helpers reached by dispatcher branches (`dispatch.py:508–523,618–670`), not primary skill rows. Their focused chat coverage lives in `test_item_intake_conversation.py:11–24` and `test_intake_simple.py:36–44`; follow those files for intake rather than inferring coverage from `primary-item-add`.
3. **Two wrapper files have no direct importer.** Adding tests just to import them would duplicate observable registry checks, and a new active-path test for retired `page.faq` would misstate its status (R2).

**No build unit recommended from this map alone.** It shows different test boundaries and two intentionally indirect wrappers, not a concrete untested regression that warrants another test file. No code, fixture, policy, or content change was made.
